## 1. Executive Summary

현재 My Chapter Book Engine은 React/Vite/Supabase가 아니다. **Node 내장 HTTP 서버 + Vanilla HTML/JS + 책별 `book.html` + Paged.js + 헤드리스 Chrome PDF**다.

본문 원본은 `book.html`이다. 서재 메타는 `book.json`, 그림은 `.image-slots.state.json`이다. 검증 도서 `books/내 포트폴리오, AI로 직접 만들기`에는 현재 html·css만 있다.

편집은 미리보기 DOM을 고친 뒤 `data-eid`로 원본 HTML 문자열을 패치한다. 쪽 나눔은 Paged.js와 `book.css` `@page`가 하고, 뷰어는 나뉜 `.pagedjs_page`를 Single/Spread/Grid로 보여 준다.

PDF는 같은 HTML을 `?pdf=1`로 열어 같은 Paged.js를 돌린 뒤 Chrome `Page.printToPDF`로 찍는다. 기본 레이아웃 규칙은 공유한다. 인쇄 재단선·워터마크·장 발췌는 PDF 전용이다.

Book Identity는 UUID가 아니라 **`books/<폴더>/book.html` 상대 경로**다. 기존 엔진은 재작성 대상이 아니다.

## 3. Current Book Source of Truth

- **Content:** `books/<folder>/book.html` — 유일한 본문 편집 원본. 장·차례·문장·상자 HTML.
- **Metadata:** 표시 제목·저자·부제는 `book.html` head/`<title>`/전면부. 서재 status·tags·coverColor·createdAt·(신규) id는 `book.json`.
- **Image State:** `.image-slots.state.json` (별도 JSON). HTML·`book.json`이 아님.
- **Render Source:** 디스크 `book.html` + 형제 `book.css` + `_shared` 뷰어/Paged.js/폰트 + image sidecar. 페이지 번호·쪽 분할 결과는 원본이 아니다.

근거: `commit()`이 `ws.write(htmlPath, next)` (`preview-server.mjs` L49–54). 재오픈은 `serveStatic`이 그 파일을 읽고 `withEditIds`만 얹음 (L296–306). `book.json`은 `readInfo`/`setInfo` (`books.mjs`). 그림은 `STATE_FILE`.

편집 → 저장 → 재오픈:

```text
book_editor.js DOM + data-eid
  → POST /__edit | /__blocks | /__structure
  → applyTextEdits / applyBlockOp / structureOp
  → (edit만) syncTocTitles
  → commit() = history.snapshot + write(book.html)
  → GET /books/<folder>/book.html
  → withEditIds(원본) + editor/tools
```

검증 도서 폴더에는 현재 `book.html`, `book.css`만 있다. `book.json`/sidecar 없어도 열기·편집·PDF는 된다.

## 4. Book Identity

**운영 키 = `file` = 워크스페이스 상대 경로** (`books/내 포트폴리오, AI로 직접 만들기/book.html`).

보조 키 = 부모 **폴더명**.

| 개념 | 값 | 제목과 같은가 |
|---|---|---|
| 표시 제목 | `book.html` `<title>` / 표지 h1 | — |
| 폴더 | `books/<folder>/` | **다를 수 있음** |
| API | `file` | 폴더 + html명 |
| `book.json.id` | 신규/복제 시 UUID 기록 | **Route가 읽지 않음** |

경로별 Identity:

| 작업 | 키 | 파일 |
|---|---|---|
| 생성 | `uniqueFolder(safeName(title))` | `books.mjs` `create` |
| 열기/저장/PDF/EPUB/ZIP/History/Cover | `file` → `ws.bookHtml` | `preview-server.mjs` `bookFrom` |
| 제목 변경 | HTML 전면부 | `updateInfo` |
| 폴더 이름 변경 | 옵션 `renameFolder`일 때만 `ws.move` | `updateInfo` |
| 복제 | 새 폴더 `원이름 사본`, 새 UUID | `.history`·PDF 제외 |
| 휴지통 | `_trash/<timestamp>__<folder>` | 폴더 통째 move |
| 복원/영구삭제 | trash 디렉터리명 `id` | `restore`/`purge` |

`safeName`은 `\/:*?"<>|`만 제거하고 한글을 유지한다. URL은 세그먼트 encode. Windows 한글 복사는 `copyDir` 파일 단위.

제목을 바꿔도 폴더를 안 바꾸면 Identity(`file`)는 유지된다. 폴더를 바꾸면 `file`이 바뀌고 클라이언트는 새 경로를 써야 한다. 지금 UUID를 키로 바꾸면 `book.json` 없는 검증 도서가 깨진다.

## 5. New Book Pipeline

```text
library.html #new-dialog
  → POST /__new-book { title, subtitle, author, source? }
  → books.create()
      → source 있으면 importManuscript()
      → copyDir(_template → books/<safeName(title)/>)
      → {{TITLE|SUBTITLE|AUTHOR|YEAR|DATE|TITLE_CSS}} 치환
      → source 있으면 toc~</body>를 import HTML로 교체, source/에 원본 저장
```

## 7. Edit / Save Pipeline

저장 버튼과 Ctrl+S는 같은 `saveChanges()` (`book_editor.js` L72, L205–210, L511–536).

```text
contenteditable → dirty eid
  → collectChanges (쪽 조각 join, pagedjs attr 제거)
  → POST /__edit { file, version:sha1, changes:[{eid,tag,html}] }
  → checkVersion
  → applyTextEdits
  → syncTocTitles
  → commit(..., "edit")   // snapshot + write
```

- DOM을 직접 고친 뒤 innerHTML을 서버에 보낸다. 별도 문서 JSON serialize 없음.
- 글 저장은 **reload 없음**. 쪽 분할은 그대로.
- 실패: alert + `저장 실패`. 409 = version 또는 eid 불일치.
- 재오픈은 디스크 `book.html`. eid는 디스크에 없음.

| 경로 | Route | History | Reload |
|---|---|---|---|
| 글 | `/__edit` | `edit` | 아니오 |
| 블록 | `/__blocks` (선저장 후) | `blocks` | 예 + 앵커 |
| 장/파트 | `/__structure` | `structure` | 예 + 앵커 |
| 제목 | `/__book/info` | `rename` (commit 우회) | watch로 가능 |
| 표지색 | `/__book/meta` | `cover` | watch로 가능 |
| 표지/본문 그림 | `/__state` 또는 `/__book/cover` | 없음 | watch 무시 |
| 되돌리기 | `/__restore` | `restore` | 예 |

## 9. History / Restore / Live Reload

| 개념 | 실체 |
|---|---|
| Save | `ws.write(book.html)` |
| History | 저장 **직전** HTML **전체** 스냅샷. 델타 아님. `.history/<ISO>__<reason>.html` |
| Restore | 스냅샷을 다시 write + reason `restore` |
| Live Reload | `GET /__live` EventSource, `fs.watch` → `event: reload` |
| Recovery | 미저장 DOM 복구 없음. 이미지 state는 History 밖 |

실제 reason:

| reason | 호출 | 비고 |
|---|---|---|
| `edit` | `commit` ← `/__edit` | 사용 |
| `blocks` | `commit` ← `/__blocks` | 사용 |
| `structure` | `commit` ← `/__structure` | 사용 |
| `restore` | `commit` ← `/__restore` | 사용 |
| `rename` | `updateInfo` | commit 우회 |
| `cover` | `applyCoverColor` | HTML 색만 |
| `import` | **없음** | `REASONS`에만 있음 |

`commit()`은 1.5초 reload suppress. watch 무시: `.history`, `_trash`, pdf/zip/epub, sidecar, `book.json`.

Auto Save를 붙일 때 위험만: html write → watch → 편집 중 리로드; 매 저장 전체 스냅샷; 그림은 기록 밖; rename/cover는 suppress 없음. 설계는 하지 않음.

## 12. PDF Pipeline

```text
뷰어 버튼 → book_tools.js 내보내기 창
  → GET /__pdf?file=&ids=&print=&wm=
  → expandIds
  → renderPdf(http://127.0.0.1:PORT/<book.html>?pdf=1&…)
```

공유: 같은 `book.html`, `book.css`, Paged.js, `image_slot`+sidecar, TOC/`target-counter`. 스크린샷 PDF 아님.

## 20. Facts Required for M0.5-B

1. Content SoT는 `book.html` 문자열이다.
2. 중간층 `htmltree` + `editable` + `blocks`가 이미 HTML 위에서 동작한다.

4. Import 출력은 toc/part/chapter + p/h/ul/ol이다.

6. 표현의 실체는 책별 `book.css` `@page`와 클래스다.
7. 설계본: `books/내 포트폴리오, AI로 직접 만들기/book.html` + `book.css`.
8. 템플릿: `_template/book.html`.
9. 포맷 플래그를 넣을 자리 후보는 `book.json`이나, 검증 도서에는 파일이 없다.

11. A는 JSON / Structured HTML / 공존 최종안을 정하지 않았다.
